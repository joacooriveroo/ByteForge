# ByteForge

ByteForge es un sitio web dedicado al hardware y los componentes de PC. Su objetivo es brindar información sobre productos, configuraciones y armado de computadoras.

El sitio cuenta con cinco páginas: Inicio, Productos, Armados, Nosotros y Contacto.

## Tecnologías utilizadas

- HTML5 para la estructura de las páginas.
- CSS3 y SCSS (Sass) para los estilos.
- Bootstrap 5 para la navegación responsive.
- AOS para las animaciones al desplazarse.
- Git y GitHub para el control de versiones.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en VS Code.
3. Instalar las dependencias con `npm install`.
4. Iniciar Sass con `npm run sass` (en PowerShell, usar `npm.cmd run sass`).
5. Abrir `index.html` con Live Server.
